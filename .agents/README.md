# GOBERNANZA DE AGENTES — POS Paletería v2

Este directorio (`.agents/`) contiene el sistema de roles, reglas, habilidades especializadas y workflows para el desarrollo autónomo con **AntiGravity** y **Google Stitch**.

- `rules/`: Reglas de arquitectura, negocio (R1 a R17) e integridad de datos.
- `agents/`: Perfiles de rol (Orquestador, Stitch Designer, Frontend Dev, Backend GAS Dev, QA Auditor).
- `skills/`: Habilidades técnicas altamente detalladas listas para el agente.
- `backlog/`: Especificación modular de tareas dividida por fases.
- `workflows/`: Procedimientos operativos estándar de desarrollo, diseño y validación.
